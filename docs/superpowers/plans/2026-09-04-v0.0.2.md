# Layer HUD v0.0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Configurable base-layer/grab-mode outlines (with a resize-handle redesign that fixes a rounded-vs-square corner clash), per-element font settings (keys, legend, layer name), settings import/export, and a README rework disclosing this is a vibe-coded project.

**Architecture:** Same pattern as every prior release — new `Config` fields flow through `get_config`/`set_config`/`config-changed` unchanged; the webview applies them as CSS custom properties. Two new Tauri commands (`list_system_fonts`, and `export_config`/`import_config`) and one new plugin (`tauri-plugin-dialog`) are the only additions to the command surface.

**Tech Stack:** Rust, Tauri 2, plain JS (ES modules), `node --test` for JS units, `cargo test` for Rust units, `font-kit` (system font enumeration), `tauri-plugin-dialog` (native save/open dialogs).

**Branching:** Each task is its own branch off `release/v0.0.2`, PR'd back into `release/v0.0.2` (squash-merge — the repo only allows squash merges). `release/v0.0.2` itself gets PR'd into `main` and tagged once all tasks land.

## Global Constraints

- macOS only; no change to build prerequisites.
- Config additions follow the existing style: `snake_case` Rust fields, `#[serde(default)]` on the struct, one control per field in `settings.html`, wired via the existing `bind`/`bindNumeric` helpers (a new `bindCheckbox` helper is added in Task 2 for bold/italic/ligature toggles and reused by Task 1's outline-enabled checkboxes).
- Theme values reach the overlay as CSS custom properties set in `hud.js`'s `applyTheme()`, consumed via `var(--x, <fallback>)` in `style.css`.
- Every new writer of config.json must go through `oryx::update_config()` (the shared lock), matching the fix already in place.
- User rule: run the `code-review` skill before every commit.

#[tauri::command]
pub fn list_system_fonts() -> Vec<String> {
    let mut names = font_kit::source::SystemSource::new()
        .all_families()
        .unwrap_or_default();
    names.sort();
    names.dedup();
    names
}

```rust
#[tauri::command]
pub fn export_config(app: AppHandle, path: String) -> Result<(), String> {
    let mut cfg = crate::config::load(&config_path(&app)?);
    // window is machine-specific; exporting it would place the overlay
    // off-screen on whatever machine imports this file.
    cfg.window = None;
    let json = serde_json::to_string_pretty(&cfg).map_err(|e| e.to_string())?;
    std::fs::write(path, json).map_err(|e| e.to_string())
}

#[tauri::command]
pub fn import_config(app: AppHandle, path: String) -> Result<crate::config::Config, String> {
    let text = std::fs::read_to_string(path).map_err(|e| e.to_string())?;
    let mut imported: crate::config::Config =
        serde_json::from_str(&text).map_err(|e| e.to_string())?;
    imported.clamp();
    let merged = update_config(&app, move |cfg| {
        // window/oryx_url/last_refresh stay owned by their existing writers,
        // same rule set_config already follows.
        let window = cfg.window.take();
        let oryx_url = std::mem::take(&mut cfg.oryx_url);
        let last_refresh = cfg.last_refresh.take();
        *cfg = imported;
        cfg.window = window;
        cfg.oryx_url = oryx_url;
        cfg.last_refresh = last_refresh;
    })?;
    use tauri::Emitter;
    app.emit("config-changed", &merged).map_err(|e| e.to_string())?;
    Ok(merged)
}
```

Register both in `src-tauri/src/main.rs`'s `invoke_handler` list (after `oryx::list_system_fonts`):

```rust

            oryx::import_config
```

```js
$('export-settings').addEventListener('click', async () => {
  const path = await window.__TAURI__.dialog.save({
    defaultPath: 'layer-hud-settings.json',
    filters: [{ name: 'JSON', extensions: ['json'] }],
  });
  if (!path) return;
  $('backup-status-row').hidden = false;
  try {
    await invoke('export_config', { path });
    $('backup-status').textContent = 'Exported';
    $('backup-status').className = 'status ok';
  } catch (err) {
    $('backup-status').textContent = String(err);
    $('backup-status').className = 'status error';
  }
});

$('import-settings').addEventListener('click', async () => {
  const path = await window.__TAURI__.dialog.open({
    multiple: false,
    filters: [{ name: 'JSON', extensions: ['json'] }],
  });
  if (!path) return;
  $('backup-status-row').hidden = false;
  try {
    cfg = await invoke('import_config', { path });
    location.reload();
  } catch (err) {
    $('backup-status').textContent = String(err);
    $('backup-status').className = 'status error';
  }
});
```

(`location.reload()` on successful import is deliberate — every control in the page needs to re-read the newly-imported `cfg`, and reloading is simpler and more reliable than re-running every binder's initial-value assignment by hand.)
